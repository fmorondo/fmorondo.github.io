📝 Transcriptor de entrevistas

Sube un audio y descarga automáticamente las transcripciones en un zip cuando el sistema termina el procesamiento.

📘 Haz clic aquí para instrucciones, sobre todo si no lo has usado.

Este sistema transcribe entrevistas y ruedas de prensa. Funciona así:

  • Elige un archivo de audio de hasta dos horas. Es mejor que le hayas puesto un nombre claro.
  • Selecciona el idioma original y la plantilla (prompt) que se usará para corregir y formatear. Hay versiones para entrevistas y para ruedas de prensa o conferencias. La versión para ruedas de prensa está todavía en una fase preliminar.
  • Pulsa en Subir el archivo y procesarlo.
  • El sistema va informando de los pasos que da. Puedes dejar la página abierta o volver más tarde: el trabajo sigue en marcha aunque cierres la pestaña.
  • Al final se descargará el ZIP automáticamente, con la transcripción bruta y la corregida.
